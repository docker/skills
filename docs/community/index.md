# Community and authoring

Docker Skills are developed in the
[`docker/skills` repository](https://github.com/docker/skills). Bug reports,
corrections, and new skills are welcome.

## Report an issue

Search the [existing issues](https://github.com/docker/skills/issues) before
opening a bug report or feature request. Include the affected skill, coding
agent, request, and unexpected result when those details are safe to share.

Security vulnerabilities should follow the repository's
[security policy](https://github.com/docker/skills/security/policy) instead of a
public issue.

## Contribute a change

Read the repository's
[contribution guide](https://github.com/docker/skills/blob/main/CONTRIBUTING.md)
before opening a pull request. Contributions must preserve the skill metadata,
evaluation, ownership, versioning, and generated-catalog contracts documented
there.

Every commit requires a Developer Certificate of Origin sign-off:

```console
git commit --signoff
```

For authoring details and local validation commands, see the
[repository guidance](https://github.com/docker/skills/blob/main/AGENTS.md).
